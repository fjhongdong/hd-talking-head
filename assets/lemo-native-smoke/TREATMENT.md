# Treatment：语义先行，选择扩张

## 三个结构候选
1. **单一 programme**：数字、比较、流程三个语义词块归入对应模板，再分到三个渠道；结尾保留“多渠道 / 多模板”。
2. **对照 spread**：左侧是只用一个模板的窄列，右侧是多渠道、多模板的宽列；通过分栏比较表达差异。
3. **垂直清单**：从语义向下滚动，逐项补齐三个内容组，最后把多个模板压成一个系统。

选择 1。6 秒内因果最清楚：语义是起点，内容类型是中间层，渠道与模板是扩张结果；不依赖人物、设备或旁白即可读懂。

## Logline / arc
同一主题先把数字、比较、流程归入对应模板，再展示三个渠道与多模板结构；从散放词块开始，落成可复用的视觉 programme。
Setup 0–2s：语义词块归入模板。Turn 2–3s：三个渠道方块补齐。Ending 2.2–6s：两个独立结论词“多渠道 / 多模板”保持可读。

## Beat sheet
- 0.00–0.70：大字“先按语义”从裁切窗上移入。
- 0.70–2.00：数字、比较、流程三种语义词块归入对应模板。
- 2.00–3.00：官方、本地、生成三个宽模块按拍点补齐。
- 2.20–6.00：两个独立结论词“多渠道 / 多模板”出现并保持。

## 构图、字级与声音
竖屏由 `innerWidth/innerHeight` 推导边距与网格，四列竖向导线和三行宽模块保持留白。全部屏显中文至少 64px，所有字左对齐。无旁白、无音乐、无字幕轨；静音输出，省略 TTS、ASR、配乐和混音步骤。

## STYLE 实现点
米白纸面、黑字、单一橙色信号；平面矩形，无渐变、阴影、粒子或噪点。进入使用 clip-reveal/wipe，位置使用 `seg` + `ss` 的精准缓动；网格线与块按拍点落位，不弹跳。网格语义化为“内容类型→渠道→模板”的 programme。

## Benchmark
学习 Zurich 国际字体风格的模块化网格、左对齐和尺度对比；不复制任何历史海报构图、机构标识或具体字形。
