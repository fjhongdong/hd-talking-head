# 阶段合同

当前生产唯一流程以 [SKILL.md](../SKILL.md) 为准：文稿整理 → 贴片和 B-roll 各自语义定量 → 一次匹配及联合分配 → 时间覆盖必要补量 → 完整清单和费用确认 → 原生 Skill 连续制作 → 一次完整合成 → 交片待用户人工终验 → 按原编号局部返修。

## 文稿与时间

读取原始素材、原稿和实际转写。以原稿纠正转写错字，不把未念出的句子加入字幕；剪除口误，处理不自然的长停顿，保留自然呼吸。以剪后口播作为音画主时钟，词锚、字幕、贴片、B-roll、头像及编号随剪后时间对齐；片头封面偏移统一应用。保留原始素材。

## 规划与授权

分别列贴片和 B-roll 语义行，数量由语义决定。每行标签匹配一次，语义适配范围内先最大化渠道、再最大化模板；最后按时间覆盖必要补量。完整清单包含编号、时间、内容、类型、渠道、模板和费用，用户一次确认。授权以实际服务、模型、调用次数和费用为界，不推断额外收费许可。

## 制作、交付与状态

按选中渠道实际调用完整原生流程和其技术 QA，独立镜头可并行。文件需可用，检查必要尺寸、帧数、时长及导出成功，保留实际来源和结果；不叠加父级逐镜语义、美观或听感质量审批。一次完整合成后交付用户，生产 `completed` 与用户 `accepted` 分开，不能自动写 `approved` 或声称用户已验收。历史阶段、审计指标和回执仅为历史记录，不是本流程的额外门槛。

执行失败先定位并最小修本 Skill，恢复受影响分支；无关素材继续。供应商结果未知先核实，不重复提交。用户提出美观、直观或听感问题后按原编号局部返修，保留未受影响素材与成果。原生 Skill 自有完整流程和技术 QA 不变。

### 转写文字校对

使用实际转写与原稿校对文字，保留实际说出的词和时码，不添加未说内容。

分离的零时长字不能直接当作可靠音尾。只有短、同说话人且有真实左右词锚的单一缺时字，才可和前词保留为有明确上界的保护词组；后词保持独立，原始转写不改。派生记录标明内部边界未知，剪辑不得按未知内部字界截断；仅有真实 PCM 静音证据时才删对应静音，不为完成流程降低阈值或扩大跨句合组。

文字更正中断后的重试只恢复同一更正清单绑定的本地发布；来源或清单不一致时拒绝，不重新发起转写。未发布的临时文件安全清理，已由事务接管的文件保留供恢复。

### 句间停顿与自然衔接

首次文稿整理时处理口误和不自然的长停顿，保留自然呼吸，以剪后口播作为时钟。

### 辅助转写按句复用

已保存的原生分句转写只作为来源参考；保留真实文件与段落时码，不冒充词级转写。
