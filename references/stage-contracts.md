# 阶段合同

当前生产唯一流程以 [SKILL.md](../SKILL.md) 为准：文稿整理 → 贴片和 B-roll 各自语义定量 → 一次匹配及联合分配 → 时间覆盖必要补量 → 完整清单和费用确认 → 原生 Skill 连续制作 → 一次完整合成 → 交片待用户人工终验 → 按原编号局部返修。

## 文稿与时间

读取原始素材、原稿和实际转写。以原稿纠正转写错字，字幕只显示实际说出的内容。保留特意录下的开场白或栏目口号，封面结束后播放该段原声及对应字幕。剪除口误、重复和异常停顿时，结合原声识别稳定低底噪与被转写词边误包的静音，保留自然呼吸和有效语音。词锚、字幕、贴片、B-roll、头像及编号使用同一剪后时钟，统一加上片头偏移。原始素材和原始转写独立保留。

转写漏报实词时长、且同一说话人的前后词都有可靠时间时，保留原始转写和原声，将实词放入已有时间锚保护的词组。保护范围内不自动剪边缘停顿，剪点落在保护范围外。

## 规划与授权

采用[视觉规划](visual-quality-contract.md)产生完整清单，由用户一次确认。授权以实际服务、模型、调用次数和费用为界，封面或转写等独立授权各自生效。已确认请求的续做与复用按[清单与授权](visual-assets-preflight.md#清单与授权)。

## 制作、交付与状态

按选中渠道实际调用完整原生流程和其技术 QA，独立镜头可并行。父级核对真实来源、输入和授权，检查文件可用、必要尺寸、帧数、时长和导出成功。常规制作一次完整合成后直接交付，由用户对本版成片做人工终验。封面实图确认、口播试听、代表样片、canary、逐镜 OCR、量框与抽帧仅按明确的任务用途处理。入库资格及历史验证记录各归对应模板和版本。生产 `completed` 与用户 `accepted` 分开登记，本版用户真实反馈后才登记接受。

执行失败先定位并最小修本 Skill，恢复受影响分支；无关素材继续。供应商结果未知先核实，不重复提交。用户提出美观、直观或听感问题后按原编号局部返修，保留未受影响素材与成果。原生 Skill 自有完整流程和技术 QA 不变。

### 转写文字校对

分离的零时长字不能直接当作可靠音尾。同一说话人的单个缺时字或连续缺时字，只有时间点按顺序落在短且真实的左右词锚内，才可和前词保留为有明确上界的保护词组。连续缺时字的首字贴着前词音尾时，仍按整组保护；保护上界使用右侧有效词的起点，不补造内部字界。右侧词保持独立，原始转写不改。派生记录标明内部边界未知，剪辑不得按未知内部字界截断。仅有真实 PCM 静音证据时才删对应静音，保持原有时间阈值和句界限制。

孤立口误因零时长挡住转写导入时，用本地源音频辨认该声的实际首尾。提交同一次 Scribe 响应、调用记录和这一个词的 `word_timing_review`，让剪辑计划可以独立剪掉口误并保留前后原声。复核区间须包含原始零时点并避开相邻有效词，原始转写保持原样。输入方式见[阶段执行](stage-runner.md#单个零时长口误)。

文字更正中断后的重试只恢复同一更正清单绑定的本地发布；来源或清单不一致时拒绝，不重新发起转写。未发布的临时文件安全清理，已由事务接管的文件保留供恢复。

### 辅助转写按句复用

已保存的原生分句转写只作为来源参考；保留真实文件与段落时码，不冒充词级转写。
