# 动效文字排版

制作时以最终 1080×1920 画面的可读性为目标，考虑组件缩放、安全区和字幕、人物小窗的避让。主标题 64px、说明文字 48px 可作排版起点；使用支持中文的清晰字体，并依内容和原生设计调整，保留文字层级。

书名和专名采用原文与正确标点，断行保持词语、专名和句意完整；画面文字须有真实来源，优先原稿，不能凭空添加事实。内部动效编号不填入原生标题、章节号或眉题；清单编号由母层统一显示，口播本身需要的章节或数值除外。核心主体与关系进入主要信息层，不让装饰字段取代正文。文字、图形与人物避免互相遮挡，阅读时间跟随实际口播时钟。图片生成文字与静态标签应如实区分来源，不能用提示词冒充实际输出。

选型时核对原生版式会突出哪些必填文字。大号字母、数字和缩写须有来源、符合本句语义，并让观众能直接读懂。必填栏只能用占位字符填充时，改选能把核心文案放在主位的模板。

HyperFrames 的 `grid-card-assemble` 用于并列单行短标签时，卡片大小随图标和文字收紧。图标和文字组成一组居中摆放，四周保留均匀内边距。让文字和图标与卡片底色有明显反差，并在最终竖屏布局中完整显示，避开人物和字幕。需要调整时，用宿主静态样式处理尺寸、间距、字号和颜色，保留原生入场动作、词锚和透明输出。

上述规则用于直接制作，不要求每个镜头 OCR、逐条量字框、原尺寸抽帧或宿主逐帧观察才能交付。原生 Skill 自身流程和技术 QA 不变；成片后的可读性问题由用户反馈，按原编号局部返修。
