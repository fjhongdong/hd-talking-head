# Stickman 受约束导演调用

适用：当前口播确实需要人物尝试、提问、回应或具体因果动作。它是导演子 Skill，不是视频生成器；真正的视频 producer 仍是 Lovart。只产出提示词不算动态 B-roll 完成。

## 准备和读取

启动先运行 `scripts/ensure_visual_broll_skills.py --project-root <project> --skill stickman-video-director`。固定提交为 `bdfcbdb8fa97a09bd4a9f1c20b857a48eb4f68fe`，仅保存在项目 vendor，不安装全局、不自动更新。

完整读取 `<project>/skill-development/vendor/stickman-video-director/skills/directing-stickman-videos/SKILL.md`，以及它的 `references/storyboard-template.md`、`references/style-catalog.md`；进入 Phase B 前完整读取 `references/omni-flash-prompt-contract.md`。原 frontmatter 有未引用冒号，按明确文件路径读取，不依赖自动发现，也不修改固定原件。

## 父级输入与覆盖规则

输入来自本次镜头资料：完整上下文、当前口播原句、A-roll SHA-256、段落 ID、24fps 整帧时窗、逐词落点、当前不能提前出现的后文结果、已选风格及人物设计、字幕与圆窗预留区。缺少同源词时码时只可制作纯视觉草稿，不能宣称声画验收。

本模式的以下规则覆盖上游整片创作默认值：

- 不重写整条故事、中文口播或事实，不强行插入五阶段情绪结构及互动 CTA。
- 不翻译成替代英文旁白；模型提示词可以英文，画面必须无声，不请求 VO、BGM 或 SFX。
- 不要求整条口播为十秒倍数。按实时 Lovart 模型能力选择生成时长；若源片长于当前镜头，预先确定原速使用区间，并保证完整动作在该区间发生。不循环、变速或冻结补时。
- 只使用本次已选风格，不默认添加真人外貌或品牌。保留上游角色比例、线宽、反变形、动作驱动及真正 9:16 重构规则。
- 保留禁止画内文字、字幕、数字、Logo、水印的规则。必要可靠文字由父级现有文字层处理。
- 父级已有内容和方向不再次询问。导演提案按结果确认模式内部审查；实质语义变化、新的付费请求或需要审美裁决时才询问用户。
- 原始 Skill 没有视频 CLI，不虚构 Stickman renderer、provider 或可执行入口。

## 实际执行与记录

1. Phase A：按上游分镜方法产出受约束导演提案，明确开始状态、前中后动作、因果变化、构图及退出状态。每个动作服务当前原句，不能用图形液化、装饰粒子或仅显字代替主体行为。
2. 宿主对照同源词时码内部审查，并记录实际审查理由；不是把历史用户的“确认”抄成这次导演批准。
3. Phase B：按原提示词合同的视觉结构产出受约束原始提示词，再转换为 Kling O1 请求。分别保存 Phase A、Phase B、转换说明和实际请求文本，不向严格 ShotRecipe 随意加字段。
4. 首帧需要图片时，调用已选图片 Skill（当前优先内置 imagegen）；检查人物、动作起点、准确竖屏与预留区。保存真实提示词、原图及来源，不能借用不相干旧图。
5. 查询 Lovart 当前模型能力及额度。请求必须使用明确的 `kling/kling-video-o1`；图生视频不能同时发送画幅参数，具体以实时说明为准。提交前取得具体镜头、次数、上传内容及费用范围的授权，只上传必要参考图。
6. 实际提交一次后保存 project/task ID。未知结果先查原任务；不自动重复付费。失败保持原来源类型，不偷偷改成代码动画。
7. 实际结果经动作、画质与规格 QA 后，使用 [现有 Lovart 原字节适配器](generated-broll-skills.md#lovart-已完成结果的原字节复用)进入公共组件执行器及 canary/assets。媒体绑定保持 `kind=ai_generated`、`provider=Lovart`，导演来源单独保存在本次调用记录。

记录保存于当前测试或 Job 的镜头资料目录，不写进 vendor，也不把测试数据固化成下期默认文案。导演记录至少包含固定上游入口与提交、实际读取的参考文件身份、当前源时钟、Phase A/B 产物与内部审查、转换差异、图片来源和真实 Lovart 请求/任务。记录本身不能代替实际视频。

## 验收边界

先看语义：谁做了什么、谁没有回应、先后因果及所需结束状态是否在使用区间可见。示意火柴人不能冒充现场实录、样本数或命名人物证据。再检查角色稳定、动作连续、手机观看清楚、没有模型画内字或声音。

原生 720×1280/24fps 无透明视频可沿父级既有规范放大；原始尺寸如实记录。父级成品仍为 1080×1920/24fps，只合成一个同源圆形头肩小窗、原声和唯一 TalkCraft 字幕轨。

一条真实镜头通过只证明该风格与调用模式，不代表所有风格、长故事、多人物连续性或任意文案已验证。未完成真实 Lovart 调用和父级合成时，标明“导演入口已准备，动态分支待实测”，不能计入可用视频能力。
