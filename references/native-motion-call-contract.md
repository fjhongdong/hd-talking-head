# 完整原生动效调用

按 [SKILL.md](../SKILL.md) 的唯一流程，分别为贴片与 B-roll 按语义定量，每项标签匹配一次，在适配候选内先最大化渠道、再最大化模板，最后按时间覆盖必要补量。渠道、模板、选项和真实调用入口保持真实身份，不把内容变化算作新模板。

用户确认完整清单与费用后，将真实原稿、语义、素材、词锚、时窗、输出规格和安全区交给选中的完整原生 Skill；原生 Skill 自主设计并执行其完整流程及技术 QA。父级交接本句要表达的对象、关系或状态，不把候选标签的惯用表现提前写成必须动作。原生可省的文案槽保持可省，不为满足适配器而填入制作编号或示例内容。不改第三方源码，不用自写动画冒充原生输出。各来源的实际入口及参数以其对应接入文档为准。

独立镜头可以并行。真实记录输入、渠道、调用和输出；检查文件可用及必要尺寸、帧数、时长，合成后检查导出成功。母 Skill 不叠加代表样片、canary、逐镜 OCR／量框、多轮抽帧或语义、美观自动打分。执行失败先最小修本 Skill 并继续受影响分支，不阻断无关素材；请求结果未知先核实，不重发。成片后按用户反馈及原编号局部返修。新增来源的资格样片和美观评估只用于入库。

执行兑现保留父级已确认的权限、原声、词锚、来源事实和真实素材身份，不能通过换 brief 扩大费用或替换来源。新增生成素材沿同一动效的既有授权和实际结果核对。原生内部选项、构图、场景代码及工程和结果路径仍由原生流程决定。

## 身份与一次匹配

渠道和模板以真实原生身份计数，语义列表、匹配和分配遵循本文及主说明。
