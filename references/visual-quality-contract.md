# 视觉规划与制作

唯一生产流程见 [SKILL.md](../SKILL.md)。贴片与 B-roll 分别按原稿和剪后实际口播列语义清单，各自确定数量。每行以完整原话、语义、画面任务和标签匹配一次，保存同用途全部已接通候选；核实适配性后联合最大化渠道，再最大化模板，最后校验时间覆盖。必要时补充有原话依据的语义项，不以拆段凑数。原项复用缓存，新增语义项才匹配。B-roll 时间占比只如实统计，不设默认目标或最低比例，不以比例倒推数量。

完整清单列出编号、类型、时间、内容、渠道、模板和费用，一次交用户确认。编号与实际镜头对应，局部返修沿用原编号。生成服务及次数以确认的费用授权为准。仅规划任务不创建制作 Job。

规划使用能力库的既有资料核实真实路线、语义适配、原稿词钟、源素材和生成依赖，不先准备每镜工程或运行各原生渲染环境。未来生成素材引用清单中的生成步骤，不填虚构的文件或哈希。原生输入、工程和结果校验在对应镜头具备依赖后执行；最终合成前统一核对全部兑现结果。

B-roll 主题画面占据竖屏画布，人物放在固定右下角圆形小窗；贴片、字幕和编号避让人物。原声、字幕、画面与编号使用剪后同一时钟，并统一处理封面偏移。默认 1080×1920、24fps；生成视频源如为 720×1280，按真实来源标记并在成片输出规格内合成。

## 文字与来源

依据原稿表达，不虚构事实。保留书名号与专名，按语义自然断行；使用支持中文的清晰字体，主标题 64px、说明文字 48px 可作排版起点。详见[文字排版](motion-text-readability.md)。真实调用、来源和输出必须对应，不伪造原生调用或生成结果。

## 制作与交付

将语义、素材、规格和词锚交选中原生 Skill 完整制作，并执行其自有技术 QA。独立镜头可并行；母 Skill 只检查文件可用、必要尺寸帧数时长和导出成功，不叠加逐镜语义、美观打分、OCR、字框或多轮抽帧验收。一次完整合成后交片，用户人工终验；`completed` 不等于 `accepted`。美观、直观或听感问题按用户反馈局部修订。能力库接入资格和样片评估与每期制作分开。

### 语义列表、匹配缓存与确认字段

语义列表是清单、评审与制作的共同输入。`quote` 是该时窗的完整原话，`semantic` 写观众应理解的命题。`visual_task` 先写能辨认的画面主体，再写观众实际会看到的动作、结果或对照。静态资料和数据可以用空间关系呈现对照。短贴片通常一个对象配一个动作，B-roll 可用实物、真实资料、界面、插画或图表呈现完整关系。必要文字负责命名、标数值、单位或来源。需要原样读出的引语、专名和章节标题可以由文字承担。用原话和词钟核对；模板、构图和材质在后续决定。`tags` 用于检索和排序。用途、真实透明出口和来源资格仍是候选边界。

检索身份与评审依据分开：评审行绑定当前 `semantic_sha256`，其原话、语义与画面任务须对应原语义行；非未知候选绑定自身 `capability_sha256`，包含实际能力、执行路线及已核验来源依据。标签和排序策略独立绑定检索，不因它们变化就让整表重审。语义或画面任务变化只让本行判断失效，单候选能力变化只让该候选的相关判断失效；新候选保持未知，同时清除受影响的旧分配与全片数量结论。显式返修授权不自动认可新适配结论，缺少评审依据也不能自动补签为通过。

宿主实际完成判断后，才把该行匹配缓存的 `semantic_sha256` 写入评审 beat，并用 `motion_match_cache.candidate_review_identity(catalog_row)` 写入候选的 `capability_sha256`。摘要只绑定判断依据，不代替判断。时窗变化清除旧分配与时间结论，保留未变的语义适配判断；依赖旧时窗的排除重新核实。

先用已有资料核实候选的原生内容槽、动作范围、字号容量、素材与费用限制。候选合格需要给出本条语义的表达依据，说明哪项实际原生能力或素材能让观众看见主体与变化。原生固定路线使用真实可消费的槽，开放路线引用表达该关系或变化的能力。过程、因果和前后对比如果只剩重复口播的文字，文字入场或装饰图标不能作为动作依据。需要额外素材时，指明现有来源、原生可绘内容或本行已列的生成步骤。`preferred` 和 `equivalent` 都须有依据。未知保留 `unreviewed`，仅当可能改善组合时补审。具体美术交接只为最终选中项准备。

一条语义包含多个必须讲清的事实或关系时，在同一行用 `required_content` 分项记录。每项有 `meaning`，确需固定文字消歧时再列 `terms`。决定候选能否适配的独立画面要点也可列为一项，便于指出哪项能力无法兑现。评审在 `expression_basis.capability` 引用能力目录的 `summary`、`editable_content/N` 或 `evidence/N`，并在 `explanation` 说明适配性。固定路线的 `content` 按必要内容 ID 提供字段路径和值。例如成员身份可绑定 `members` 的 `/data/say` 为「宝妈 · 前货车司机」。制作时沿用已确认的含义与槽位。开放创作保留原生对构图和动作的决定权。

把改变句意的限定词写入本行必需内容。图标只能表现主体或情绪时，用短文案或可辨动作补齐时长、范围或条件。例如原话的重点是「喜欢了很多年」，爱心可以辅助表达喜欢，「很多年」也要在画面里看得出来。

先完成全片联合分配，再核对选中组合的具体时窗、词锚与阅读停留。失败时仅排除该候选在本窗的用法并复用缓存重分配；覆盖不足才回对应语义列表补项，不为保留某渠道改数量或放宽检查。

没有完整已评审组合时，明确记录“尚无完整已评审解”，不伪造零渠道或零模板的最优数。仍从完整剩余候选求未知组合并在末尾校时；时间通过后才交给宿主补充其中必要的适配判断，时间候选耗尽则报告不可行。缩减待审组合只影响当轮试解，重选始终从原缓存完整集合出发，仅扣除已证明失败的具体用法。同次入口复用已校验匹配和分配结果，不另建持久缓存或重复执行整套求解。

对外区分：当前已核实候选内的数量最优、加入未知候选的乐观上界、实际已交付的渠道与模板数。前两者相等只说明当前候选范围的数量结论，不证明画面已完成或足够多样；还有可能改变结果的未知项时不得称已最大化。实际计数以真实执行身份为准。

### 画面多样性

在语义适配候选内先最大化渠道，再最大化真实模板，不靠不适配画面凑数量。新来源接入时以美观优先；实际分配不把审美偏好提前放到两个数量目标之前。模板别名归一，同模板换文案、颜色或构图仍计为一个模板。

同一渠道或模板复用时，原生准备与执行动作引用现有已确认整表，使原生能读取本片相关项的原话与语义。要求各项按自身对象、关系与变化独立创作，保留原生风格，避免仅换字复用同一卡片；父级不指定每项内部动作，不新增逐镜美观评分、预览或审批。交接方式见[完整原生调用](native-motion-call-contract.md)。

### 动效创作要求

先让主体可辨，再按关键口播推进动作，为结果或条件留出阅读时间。用一个问题检查计划是否直观：暂时遮住辅助文案，还能看出核心动作或关系吗？数字、单位、专名与来源可以继续靠字读。原生流程据此选择构图和表现手法。比如「工具费省二十，多花一小时返工」可以画钱从账单移出，修改稿被退回，计时推进，文字只保留「¥20」「+1 小时」。两种单位各自展示。

- 数值对比用同一单位并列两种状态，标清各自含义。用长度表示耗时等数值时，两侧共用尺度。表达提前或延后时，明确变化方向和时差，示例时点标为示意。
- 用量、步骤和条件通过可见动作和对应反馈表达。每次使用与该次用量记录相对应，区分记账笔数和实际用量。多次满足条件后仍待决定的事，画面停在待决定状态。
- 对比两个工具能否处理同一任务时，让观众看到同一输入分别进入两路，每路都有可辨的结果或完成状态。把速度、质量或返工差异留给对应的口播段。
- 表现省错成本时，交代表面省掉的项目，再用可见的任务动作或短标签揭示实际代价，例如从低价标签转到反复返工。警示图标只辅助表达。
- 前后场景用关键动作、道具和空间一起区分。表现下班后的私人时间时，可让人物合盖离开工作位，再进入有明确休闲活动的家中场景。
- 团队构成保留原话明确提到的成员身份。人数、协作方式和成员身份各有含义。只知道团队里有哪些人时，用组级身份说明即可，避免暗示各类人数或猜测具体成员。
- 抽象结果先明确它属于什么。创业受挫可用创业材料与失败痕迹建立关联。表达先后或条件时，给前一阶段可见的达成结果，再进入下一阶段。只有钟、叉号等通用符号时，用短标签消歧，并结合相邻画面体现行动。
- 表现检查或验收时，先亮出被检查的交付物，再让观众看见检查动作和结果。相邻镜头接着表现交付时，保留能认出同一交付物的视觉线索。例如先看到成片预览和播放进度，再在同一画面显示「验收通过」，交付时仍能认出这条成片。
- 需要表现过程或状态变化时，让主体的动作推动句意，并为关键变化和末态留出观看时间。卡片入场和轻浮动可作辅助。表达「尚未检验」时，让观众看见什么要接受检验、由谁或在哪个场景检验，以及尚待完成的状态。原生 Skill 决定具体动作和构图。

每镜突出一个视觉重点，主信息与辅助信息有清楚的字号、位置和色彩层级。对齐同类元素，保持间距和留白一致，用与原生风格相符的材质、光线和配色收束画面。按竖屏观看尺寸考虑阅读和避让，标题、字幕、人物小窗与编号各有位置。创作和检查沿用原生流程。

### 痛点场景与人物感受

原稿涉及痛点时，交接实际困难与人物感受，不增加原稿没有的事实。
